# 策划数值表

这些 Excel 是正式高难版本的数值来源，按内容类型分文件，同类配置分为页签。

| 文件 | 调整内容 |
| --- | --- |
| 角色与成长.xlsx | 职业基础属性、祝福、经验、营地成长 |
| 怪物与关卡.xlsx | 怪物和首领属性、招式、阶段、出怪安排、成长曲线、关卡状态 |
| 主动技能.xlsx | 技能效果、等级成长、选择频率 |
| 装备与掉落.xlsx | 装备基础属性、部位、品质、成长、药剂和装备掉落 |
| 场地效果.xlsx | 增益/减益区域效果、预告、持续时间、数量、覆盖范围 |
| 战斗与地图.xlsx | 难度节奏、伤害计算、闪避、地图、刷怪和战斗参数 |

每份表的“使用说明”列出编辑方法。蓝色数字可调整，百分比直接按百分数输入；引用其他内容时选择中文名称，多个对象用顿号分隔。编号用于保持内容对应关系，请保留已有编号。宽表已冻结标题和前两列，可以向右查看属性。

装备增加基础属性；同类祝福的增幅相加，不同乘区再相乘。怪物先计算模板和成长曲线，再应用“关卡状态”；要提高整个无尽过程的基础强度，调整“怪物”或“基础成长”，要改变特定关卡的压力，调整“关卡状态”和“出怪安排”。

修改完毕后保存并交给开发校验、导出、打包。程序字段和对应关系保存在开发工具中，策划无需编辑。开发使用的临时简单测试参数独立保存，正式试玩 APK 使用这里的高难配置。
