## 运行与验证

用Godot标准版导入 `project.godot`，按F5运行。键盘WASD或方向键移动，按住J攻击，K技能，空格闪避，Esc暂停。

在项目根目录执行：

```powershell
./tools/run.ps1          # 电脑上运行游戏
./tools/run.ps1 -Editor  # 打开Godot编辑器
./tools/run.ps1 -Check   # 战斗、场地、界面与动画回归
./tools/build-android.ps1
```

当前构建为 `0.7.0-dev`，APK输出到 `builds/android/ember-hero-debug.apk`，本轮交付副本为 `builds/android/ember-hero-0.7.0-hard-debug.apk`。正式试玩包使用高难数值；临时简单配置独立保存在 `design/profiles/qa-easy.json`，供电脑流程测试使用。游戏与调试密钥、引擎、构建产物分别管理；测试使用独立存档，不写入正式玩家进度。

## 已实现的玩法

- 圣光骑士、冰霜法师、逐风游侠；局外水晶解锁与有限生命成长。
- 按住普攻、主动技能、闪避；圆形图标按钮、环形冷却与圆形命中区域，支持手机多点触控与键盘操作。
- 经验拾取、暂停三选一升级；所有机制可以组合，没有铭文槽位限制。
- 无尽40秒普通节点、精英、每5节点Boss，胜利后继续下一轮。
- 三位Boss在65%和25%生命时变招：环形震波、环射与召唤、多落点重击、组合攻击和持续危险区域；后续循环使用进阶组合。提高基础生命、伤害与成长，保留预告和闪避窗口。
- 3600×2400大地图，镜头跟随勇者并在真实边界停止；怪物在玩家240–470距离的屏幕内有效区域随机出现。
- 八种场地：减速、输出减益、持续伤害、暴击增益/减益、控制时长、攻击间隔与承伤增益。每轮各区域独立选型且不重复、保持间距；打乱袋轮换，持续32–48秒，3秒预警，区域数量、大小和位置变化。
- 少量生命药剂掉落与受伤保底；满血时留在地上，拾取恢复生命。掉落间隔与地面数量有界。
- 三职业各三种主动技能，每四级选择强化或替换，保留已学等级和当前冷却。
- 武器、护甲、饰品、靴子四部位，三种品质，拾取比较后替换；每局重置装备，局外解锁类型。装备提供基础属性，同类祝福增幅加算，不同乘区相乘。
- 六份中文 Excel 统一维护数值，构建时导出校验，运行时缓存轻量定义。怪物先按曲线生成基础属性，再应用独立关卡状态，包含等级、防御和抗暴击。
- 独立Boss血条与离屏方向提示、普通节点的怪物潮进度及蓄势/高峰/喘息节奏。
- 12套Q版西幻动作图集，每套待机/移动/攻击/受击各4帧；运行时纹理512×512并共享使用。
- 设置、暂停、后台恢复、死亡结算、版本化本地存档、原创配乐和音效。
- 远征检查点：运行中每20秒、升级与节点变化、切后台或关闭时保存；营地可继续同一局，重开仍从1级开始。
- 暂停与升级时查看属性及所有祝福；营地回看上一局成绩和构筑，显示基础属性与场地实际收益。

测试说明与结果见 [电脑测试记录](docs/qa-2026-10-10.md)。真机调试按用户要求暂缓，本轮使用电脑与Android 36模拟器。

## 开发环境

建议 Godot 4 标准版 + GDScript。桌面玩法调试只需Godot；引擎解压即可运行。

安卓APK打包需对应版本的Godot导出模板、Java 17及Android SDK。SDK可以通过Android Studio或官方命令行工具获取。真机调试还需手机开启开发者模式和USB调试。

已安装Godot 4.7.2到项目 `.tools/godot/` 并通过官方SHA256校验。已验证 `D:\jdk17\jdk-17` 提供Java 17，`D:\AndroidSDK` 包含Android平台与Build Tools、ADB及 `Medium_Phone_API_36` 模拟器。安卓模板在 `.tools/android-templates/`，取得与校验记录见其中的 `download-manifest.json`。APK已完成调试签名及校验。

其他电脑只运行桌面版时需要Godot标准版；安卓导出另需Java 17、SDK及匹配引擎版本的导出模板。可在 `build-android.ps1` 中通过 `-AndroidSdk` 和 `-JavaSdk` 指定安装路径。引擎路径支持用户环境变量 `GODOT_BIN`。

工具下载存放在 `.tools/`，构建产物放在 `builds/`；两者不纳入Git。具体SDK组件版本以选定Godot版本的官方导出文档为准：
https://docs.godotengine.org/en/stable/tutorials/export/exporting_for_android.html
