# 安卓无尽肉鸽：制作草案

## 已确认需求

- 安卓手机、横屏、Q版角色与怪物。
- 每局从1级开始；没有固定通关时间，存活就能继续。
- 左手控制移动，右手承担少量战斗操作。
- 成长包含个人属性，可结合经验、装备与技能构筑。
- 外部素材可下载到项目，但需记录来源、许可、用途。

## 已确认的玩法选择

- 按住右侧普攻按钮持续攻击，另有技能与闪避。
- 西幻勇者对抗邪恶势力，2D俯视角。
- 每局等级归零，保留少量局外成长和解锁。
- 无尽关卡节点，定期Boss，其余节点安排精英与小怪。
- 测试设备为红米K80；第一版离线单机。安卓版本待真机读取。

## 制作方向

采用 Godot 4 标准版、GDScript、2D Compatibility 渲染。先把移动、攻击、受伤、拾取经验、升级选择、死亡重开做成安卓可玩闭环，再扩充内容。

题材：小小勇者从城堡庭院开始对抗邪恶势力。已接入手绘风格Q版角色、怪物、Boss及独立动作图集；正式素材随版本维护。

左侧虚拟摇杆；右侧最多三个主要按钮。升级选择时暂停战斗；暂停按钮放在顶部。摇杆和战斗按钮需要支持不同触点同时按住，避免移动被技能操作打断。

玩家可组合全部成长机制。关卡通过场地buff/debuff轮换改变走位与输出收益，保留预警和安全区域。正面区域提升暴击或控制时长，负面区域影响移速、输出、暴击或持续掉血。

用户于2026-10-10明确暂缓真机调试，当前验证在电脑与安卓模拟器完成；真机性能验收留在后续阶段。

## 第一版验收目标

- 安卓真机上横屏启动；左右手同时操作正常。
- 从1级开始，击杀、经验拾取、升级选择形成闭环。
- 不同升级能改变玩法，而非全部只是增加百分比。
- 普通怪、冲锋怪、远程怪和精英提供可读的危险提示。
- 无固定终局；死亡结算，能够重开。
- 暂停、切后台与恢复不造成玩家无意受伤。
- 长时间运行时敌人、掉落物、特效数量受控；具体性能目标根据测试手机确定。
- 素材许可记录、打包说明、数值配置和试玩记录齐全。

## 后续开发顺序

1. 确认玩法，准备引擎与项目骨架。
2. 桌面验证基础战斗和升级，再验证安卓多点触控。
3. 接入统一风格素材、怪物组合、精英与构筑。
4. 调整前10分钟曲线，做长局与真机性能测试。
5. 完成APK交付；根据实测结果继续迭代数值。
