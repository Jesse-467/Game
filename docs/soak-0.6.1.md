# 30分钟实际渲染与正常成长验证

日期：2026-10-13。版本0.6.1-dev，电脑AMD Radeon780M，1280×720 OpenGL，60FPS上限。使用正常骑士、零营地成长，固定种子11、多弹成长偏好；未改变玩家/敌人生命、伤害或刷怪参数。

## 方法

`tools/soak_playtest.gd`运行实际应用场景和物理更新，给输入控制器提供自动走位与持续攻击；技能、闪避、经验、升级、节点、Boss与场地均走原游戏流程。进度使用隔离内存仓库，不写玩家存档。

自动策略与CPU模型共用`playtest_policy.gd`。提取策略后，对9组骑士模型的13类结果进行比较，包括每分钟记录、伤害、等级、击杀、构筑、场地损伤、Boss和首升时间，没有轨迹差异。策略没有全面躲避弹体，也不能代替人工手感评价。

统计使用固定大小、0.1ms精度的直方图，每分钟记录一次资源状态及截图，避免采样数组本身随每帧持续增长。最大帧间隔保留原始值；截图读取和PNG保存属于测试过程的同步任务，未单独剔除其耗时。

## 复现

```powershell
& ./.tools/godot/Godot_v4.7.2-stable_win64_console.exe --path . --script tools/soak_playtest.gd --disable-vsync --position -2400,-2400 -- --seconds=1800 --report=res://builds/reports/render/soak-30min.json
```

运行需要真实图形驱动，headless模式会拒绝该测试。缩短秒数可检查探针是否工作，但不能替代完整长局结果。
