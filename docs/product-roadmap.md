# 勇者余烬：产品方向与交付路线

## 产品定位

安卓横屏、离线单机、2D俯视角的西幻Q版动作肉鸽。玩家通过走位、按住普攻、主动技能和闪避，完成一轮又一轮关卡节点。核心体验是从弱小勇者成长为拥有鲜明战斗风格的角色，再面对新的敌人组合和Boss变招。

用户确认本项目按正式产品建设。可玩里程碑用于验证产品，不是将最终目标缩减为演示程序。

## 长期可玩性的支柱

1. 操作决定生存：危险提示清楚，攻击可躲，闪避有冷却。死亡时能解释原因。
2. 构筑改变战斗：成长需要改变弹道、命中效果、范围、资源和技能联动，而非只累加攻击力。
3. 节点形成节奏：普通怪提供成长，精英打破惯性，Boss检验构筑与操作，胜利后短暂恢复。
4. 局外解锁提供目标：新武器、角色和祝福拓宽选择；永久数值成长有限，不替代操作。
5. 内容可扩展：新敌人、武器和祝福通过稳定ID和内容定义接入，避免每次改动主循环。

## 首个正式版本的内容目标

建议目标，后续依据试玩与制作成本调整：一个完整可重复的无尽模式，三个可解锁角色/武器方向，至少三种可辨识构筑，六种普通/精英敌人，三种Boss，多轮节点的敌人组合变化。不同Boss至少有两类可辨识攻击行为，后续循环通过变招和组合增加挑战。

当前已有圣光骑士、冰霜法师和逐风游侠，角色改变普攻与主动技能。玩家可按清场、控制或精英猎杀等成长偏好构筑，并在长局中组合全部机制。场地轮换改变这些机制的实际收益与站位需求。

正式版本还应具备：营地解锁、结算与记录、设置、音量控制、触控尺寸调整、暂停与切后台处理、版本化存档、资源署名、APK与安装说明。长局体验须完成实际测试。

## 数值验收方法

初期跟踪首升时间、前三分钟等级、第一次Boss到达率、Boss战时长、死亡原因、升级选择率和不同构筑表现。指标用于定位体验问题，不以单个平均数取代试玩判断。

无限模式不承诺无限时间都同样轻松。应保证没有脚本强制死亡，玩家能通过读招和搭配延长存活；后期避免只靠血量膨胀制造无聊。每轮Boss前后要让玩家感到节奏变化。
