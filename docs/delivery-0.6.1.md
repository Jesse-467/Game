# 开发交付：0.6.1-dev

当前交付为安卓横屏、完全离线的Q版西幻无尽肉鸽。代码、素材、数据、测试和开发文档保存在本地Git分支`codex/ember-hero-game`。

## 运行

电脑：在项目根目录执行`./tools/run.ps1`，WASD/方向键移动，按住J攻击，K技能，空格闪避，Esc暂停。`-Editor`打开Godot项目；`-Check`执行回归。

安卓：APK位于`builds/android/ember-hero-debug.apk`。将文件传到手机，在文件管理器中打开并按系统提示安装。用户当前暂缓真机调试，电脑Android36模拟器用于平台验证。

桌面开发使用已安装的Godot4.7.2标准版。安卓构建另使用Java17、AndroidSDK与匹配导出模板；路径、获取方式和构建命令见README的开发环境部分。引擎、SDK缓存、构建结果与调试密钥均与源码分开管理。

## 已交付的完整流程

- 三个角色，每局从1级开始；击杀、经验拾取、三选一成长、死亡结算、重开、局外解锁形成闭环。
- 大地图和跟随镜头、屏幕内安全距离随机刷怪、精英与每5节点Boss、半血与后续轮次变招。
- 八种临时场地、随机类型/区域轮换和预警；全部祝福可组合。
- 左侧摇杆和右侧三个圆形战斗按钮，多点触控、暂停、后台恢复、继续远征和旧档迁移。
- 属性与祝福详情、上一局记录、设置、原创声音、12套动作图集和正式场地美术。
- 分离的模拟、输入、表现、内容和保存模块；新增内容通过稳定ID、JSON定义和对应行为接入。

0.6.1补充局外保存的写入错误检查：刷新失败时不替换原存档，不将该次结算当作已保存；使用已有提交失败保留检查点的流程。与0.6.0相比，战斗数值和画面不变。

## 验证依据

0.6.1完整回归保持252项命名规则检查通过，另有500组空间查询和实际视口多指检查。0.6.0的地图测试包含1000个刷怪位置样本、相机和HUD验证、场地随机袋和旧记录迁移；自然成长模型27组中19组达到30分钟。具体规则、策略与限制见`world-0.6.0.md`。

真机性能和人工试玩反馈仍按用户后续安排进行；电脑渲染与自动模型的结果保持各自测试范围。远程Git仓库未执行推送。
