# 数值、场地与难度方案 v0.6

当前方案经电脑模型与回归检查，游戏体验仍需持续试玩调整。实际参数分别来自 `data/balance.json`、`enemies.json`、`characters.json`、`upgrades.json`、`arena_afflictions.json`；删除了未被游戏使用的重复怪物/Boss参数，避免调错数值来源。

## 成长与战斗

骑士初始生命100、移速230逻辑像素/秒、基础攻击12、间隔0.65秒。最早的史莱姆生命24，需要两次基础命中；敌人类型有不同生命、移速、经验与攻击行为。受伤保护0.65秒；闪避3秒冷却、0.2秒位移并提供0.3秒伤害保护。

经验需求为 `round(8 + 4*(L-1) + 1.2*(L-1)^1.25)`。击杀掉落经验，靠近拾取；升级暂停并三选一。0.6的取经验/接近Boss模型首升8.4–12.4秒，第一Boss在160秒进入战场。实测范围见测试记录，模型不代表新手操作体验。

现有机制包含多弹、贯穿、命中爆炸、减速、暴击、精英增伤与技能冷却成长。玩家可以组合所有机制。重复选择有各自数值范围，满级选项移出抽取池；25级之后开放持续的线性属性成长。不存在限制机制组合的铭文槽位。

## 节点与无尽压力

普通节点40秒，每5节点安排Boss；Boss必须被击败才能继续。第3类节点混入精英，每个新节点有少量恢复和初期减压。节点回血只作用于仍存活的角色，不能在致命伤与Boss死亡同时发生时复活玩家。

普通敌人生命倍率为 `1 + 0.10*t`，伤害倍率为 `1 + 0.035*t`，t单位为分钟；移速倍率最大1.25。三种Boss按顺序轮换，各自以两种攻击开场，在半血后变招，第二次登场使用进阶组合；每完整轮换后的生命倍率增加0.85。不会设置定时必死或固定终局。

0.6普通节点按0–8秒蓄势、8–25秒渐强、25–34秒怪物潮、34–40秒喘息编排。基础间隔`max(0.40, 1.15/(1+0.10*t))`；蓄势/喘息乘1.65，高峰乘0.72，Boss杂兵乘2.4。新怪在屏幕有效区、玩家240–470距离的环带内随机出现；出生提示期间不能攻击玩家，玩家可以提前命中。参数在`balance.json`，参考与验证见`world-0.6.0.md`。

0.4.0的Boss半血阶段保留至少1.1秒前摇，切换后再给予至少0.8秒准备。魔像震波提供内圈与外侧两条避让路线；骸骨君主环射保留弹道间隙，召唤点先标出；烬焰领主重击提前锁定三处/五处落点。第二轮增加组合与密度，前摇不因轮次无限缩短。高输出可以快速击败Boss，没有强制半血锁血。具体参数与验证见 `boss-0.4.0.md`。

敌人最大120、弹体最大240、特效最大128、掉落物最大180。经验掉落达到上限时合并数值，避免丢失经验。达到敌人上限时仍为必要Boss保留生成机会。

## 场地改变收益与站位

前两节点没有场地效果。从第3节点开始使用独立时钟轮换八种场地，节点变化不重新计时。类型采用打乱袋，每袋包含全部类型，袋边界避免立即重复；空间位置使用9格打乱袋与格内随机偏移。

| 场地 | 区域内效果 | 主要取舍 |
| --- | --- | --- |
| 寒霜地脉 | 移速×0.75，闪避速度正常 | 稳定输出或优先离开减速区 |
| 鹰眼圣阵 | 发动攻击的暴击率+25个百分点 | 留在增益区输出或避开敌人包围 |
| 虚蚀结界 | 发动攻击/技能的伤害×0.70 | 降低风险转移站位或继续清理近处威胁 |
| 共鸣法阵 | 发动控制的时长×1.50 | 在区域内组织控制，或迁移追赶经验 |
| 烬火侵蚀 | 持续暴露每秒6伤害 | 取回经验或优先脱离区域 |
| 迷视结界 | 发动攻击的暴击率-20个百分点 | 暂时依赖普通伤害或离开恢复暴击收益 |
| 战意圣阵 | 发动普攻的间隔×0.80 | 争取更高攻击频率或优先避让危险 |
| 守护法阵 | 区域内承伤×0.75 | 在防护区应战或转移追赶经验 |

首次有8秒蓄势；每轮3秒位置预警，生效32–48秒，随后6秒转场，结束前6秒提示下一类型。通常3–5个圆形区域，半径约110–155；数量、大小和位置变化，区域锚定在世界中。圆面积总和上界不超过可见地图38%，留下可走位区域，地图本身大于视口。

暴击概率限制在0–100%，这是概率边界，角色的永久成长不被改写。弹体记录发射时的场地输出、暴击和控制倍率；离开后新攻击恢复正常，已发动的攻击保持其来源效果。较弱的普攻减速不会提前覆盖更强的技能控制。

暂停和升级选择冻结场地计时及伤害。正负区域用不同颜色、中心符号和文字状态显示；场地本身不删除武器、铭文或能力。

## 验证与后续调优

固定种子运行实际60Hz战斗模型，对照规避/忽略负面场地两种策略。记录首次升级、Boss到达/击败时长、等级、死亡原因、场地伤害、实体峰值与每步CPU时间。CPU模型不包含GPU渲染成本。

下一阶段通过人工试玩检查取舍是否清楚、正面区域是否值得冒险、负面区域是否容易辨认，以及不同角色的技能是否好用。必要时调整区域时长、强度和怪物组合，不以强制机制限制替代体验调优。
